# analysis-core bundled data

## opening_book.bin

Polyglot opening book derived from the **Lichess broadcast PGN archives** for
2025-02, 2025-03, and 2025-04 (combined). Generated by
`packages/analysis-core/scripts/build_book_from_broadcasts.py`.

- **Format**: Polyglot binary (16-byte entries: u64 zobrist + u16 move + u16 weight + u32 learn, sorted ascending by key).
- **Source dataset**: <https://database.lichess.org/broadcast/> (CC-BY-SA 4.0).
- **Source archives** (sha256s match `database.lichess.org/broadcast/sha256sums.txt`):
  - `lichess_db_broadcast_2025-02.pgn.zst` (sha256: `f92d0fea95e6c733898a920c0790a8c02f3f8a1e1c9ca0c42f15330cd5430434`)
  - `lichess_db_broadcast_2025-03.pgn.zst` (sha256: `840bdb7d640f82032f8373c86efcb69d0801c0d54cf3edf2152e4b8d25b8da87`)
  - `lichess_db_broadcast_2025-04.pgn.zst` (sha256: `6b6fd9e9e79a94e80d0f556fb323ad951922fdff1f42089fc18a348e65d79624`)
- **Retrieved at**: 2026-05-24T22:21:00Z
- **Build parameters**: `--max-ply 20 --min-weight 1`.
- **Games scanned**: 60,644 OTB broadcast games.
- **Entries written**: 425,062.
- **Size**: 6,800,992 bytes (≈ 6.5 MB).
- **sha256**: `dd0c9b50f75274b421ee9bfa12b45920b38124c9e2c7768f1179d130357c4532`

To reproduce:

```bash
for month in 2025-02 2025-03 2025-04; do
  curl -L -o /tmp/broadcast-${month}.pgn.zst \
    https://database.lichess.org/broadcast/lichess_db_broadcast_${month}.pgn.zst
  zstd -d /tmp/broadcast-${month}.pgn.zst
done
cat /tmp/broadcast-2025-02.pgn /tmp/broadcast-2025-03.pgn /tmp/broadcast-2025-04.pgn \
  > /tmp/combined.pgn

uv run python packages/analysis-core/scripts/build_book_from_broadcasts.py \
  --input /tmp/combined.pgn \
  --output packages/analysis-core/data/opening_book.bin \
  --max-ply 20 \
  --min-weight 1
```

Verify by:

```bash
uv run pytest packages/analysis-core/tests/test_real_book_coverage.py
```

A synthetic stub book covering 8 mainline openings to 12 plies (81 entries,
1,296 bytes) shipped with feature 004 Phase 1 to unblock the pipeline without
external download dependencies. That stub was replaced by the real
Lichess-derived book above as part of feature 005 Phase 2.
